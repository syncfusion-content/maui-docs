# API Reference for .NET MAUI Sunburst Chart

<br>

The Sunburst Chart API is documented across the pages below. Each page lists the public properties, methods, and events declared by a related group of classes.

<tr>

<tr valign="top">

        <code>data labels</code>, <code>tooltip support</code>, <code>selection behavior</code>,
        <code>legend integration</code>, <code>animation</code>, <code>segment appearance</code>,
        and overall <code>chart layout</code>.

</tr>

<tr valign="top">

        <code>SunburstToolbarSettings</code>. Use this reference for
        <code>legend visibility</code>, <code>legend placement</code>,
        <code>toolbar positioning</code>, <code>icon styling</code>,
        <code>background customization</code>, and other
        <code>shared visual appearance settings</code>.

</tr>

<tr valign="top">

        including <code>SunburstTooltipSettings</code>,
        <code>SunburstSelectionSettings</code>,
        <code>SunburstSelectionChangingEventArgs</code>,
        and <code>SunburstSelectionChangedEventArgs</code>.
        Use this reference for <code>enabling and customizing tooltips</code>,
        <code>segment selection</code>, <code>selection highlighting</code>,
        <code>selection modes</code>, and handling
        <code>selection-related events</code>.
    </td>
</tr>
