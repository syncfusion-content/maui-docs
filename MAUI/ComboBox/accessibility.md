# Accessibility in .NET MAUI ComboBox

[SfComboBox](https://help.syncfusion.com/cr/maui/Syncfusion.Maui.Inputs.SfComboBox.html) provides built-in accessibility support for assistive technologies such as screen readers. The following table lists each element and the value announced by the screen reader.

| Element | Value |
| --- | --- |
| InputView | When a placeholder is set, the screen reader announces the placeholder text along with the ComboBox name. When an item is selected, it announces the selected item value. |
| ClearButton | Clear Button, Double Tap to Activate |
| DownButton | Down Button, Double Tap to Activate |
