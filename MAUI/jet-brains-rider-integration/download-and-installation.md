# Download and Installation Guide 

[Essential MAUI](#essential-maui)

[Essential UI Kit](#essential-ui-kit)

## Essential MAUI
Syncfusion® publishes the JetBrains Rider extension through the JetBrains Marketplace and supporting release channels. You can install it directly from JetBrains Rider or download and install it from the marketplace package.

**Prerequisites**
The following software prerequisites must be installed to use the Syncfusion® .NET MAUI extension, as well as for creating projects and adding snippets in Syncfusion® .NET MAUI applications.

* [JetBrains Rider](https://www.jetbrains.com/rider/download/)

* [C# support for Rider](https://www.jetbrains.com/products/?type=team&lang=csharp)

* [.NET 8.0 SDK or later](https://dotnet.microsoft.com/en-us/download) with the .NET MAUI workload (`dotnet workload install maui`)

## Install through JetBrains Rider
The following instructions outline the process of installing the Syncfusion® .NET MAUI extension from JetBrains Rider.

1. Open JetBrains Rider.

2. Open the Plugin dialog from **Settings/Preferences > Plugin**.

3. Search for **Syncfusion® .NET MAUI** in the JetBrains Marketplace tab.

4. Install the **.NET MAUI tools - Syncfusion®** extension by clicking the Install button.

5. Restart JetBrains Rider after installation.

6. You can now create a new Syncfusion® .NET MAUI application using the Syncfusion® .NET MAUI extension from JetBrains Rider.

## Install from the JetBrains Marketplace

The following instructions outline the process of downloading and installing Syncfusion® .NET MAUI applications from the JetBrains Marketplace.

1. Open the Syncfusion® .NET MAUI extension listing in the [JetBrains Marketplace](https://plugins.jetbrains.com/).

2. Select **Install** from the marketplace. If prompted, choose **Open JetBrains Rider** to continue the installation.

3. Install the **.NET MAUI tools - Syncfusion®** extension by clicking the Install button.

4. Restart JetBrains Rider after installation.

5. You can now initiate the creation of a new Syncfusion® .NET MAUI application using the Syncfusion® .NET MAUI extension from JetBrains Rider.

## Manually Installing an Extension in JetBrains Rider

The following instructions detail the manual installation process of the Syncfusion® .NET MAUI extension in JetBrains Rider.

1. Download the plugin package from the JetBrains Marketplace.

2. In JetBrains Rider, open **Settings/Preferences > Plugin**.

3. Click the gear icon and choose **Install Plugin from Disk**.

4. Browse to the downloaded plugin package and install it.

5. Restart JetBrains Rider after installation.
