# Creating a Syncfusion® .NET MAUI application

Syncfusion® provides a .NET MAUI project template for building applications with Syncfusion® components in JetBrains Rider. This template includes the necessary components, NuGet references, namespaces, and code snippets needed for development. It also includes a project wizard that streamlines the process of creating .NET MAUI applications using Syncfusion® components.

N> Syncfusion® JetBrains Rider project templates now support .NET MAUI project templates starting from `v25.1.35`.

The following steps will help you create your **Syncfusion® .NET MAUI application** through **JetBrains Rider**:

1. To create a Syncfusion® .NET MAUI application in JetBrains Rider, open the Project Wizard or use the Syncfusion® template from the New Project flow.

2. Select **Syncfusion® .NET MAUI Template Studio: Launch** and press **Enter**. This opens the Template Studio wizard for configuring your application. Enter a unique **Project Name** and specify the **Project Location** where your project files will be saved.

3. To select a component, click the **Next** button or the **Components** tab. From there, you can add the desired Syncfusion® .NET MAUI components to your application.

4. Select the required component(s) by clicking the corresponding checkbox. To unselect a component, click the checkbox again or remove it from the selected component list.

5. The features for the selected controls will be displayed when you click the **Next** button or the **Features** tab. From there, you can select or unselect the desired features for your selected components.

6. In the **Project Summary** section, you can customize the **Project Name**, **Project Location**, selected components, **Core Version** (.NET 9.0 or .NET 10.0), and **Theme** (Material Light or Material Dark).

7. Click the **Create** button to generate the Syncfusion® .NET MAUI application. The created application includes the necessary Syncfusion® NuGet packages and rendering code for the selected components.

8. To view the Syncfusion® components in your application, run it from JetBrains Rider using the standard run configuration for the created .NET MAUI project.

9. If you installed the trial setup or NuGet packages from nuget.org, you must register the Syncfusion® license key to your application.
