# Series API in .NET MAUI Circular Chart

This page lists the public properties, methods, and events of the CircularSeries base class and every circular series type derived from it.

## Classes on this page

Each class lists only the members it declares. Members shown against a base class are inherited by every type derived from it.

<table>
<tr>
    <th>Class</th>
    <th>Description</th>
</tr>

<tr valign="top">
    <td><a href="https://help.syncfusion.com/cr/maui/Syncfusion.Maui.Charts.PieSeries.html" aria-label="View PieSeries class in API reference">PieSeries</a></td>
    <td>Plots <code>categorical data</code> as <code>circular slices</code>, where each slice's sweep is proportional to its value. Supports <code>slice explosion</code>, <code>slice grouping</code> into an <code>"others" segment</code>, <code>custom center content</code>, and configurable <code>start and end angles</code> for <code>partial pies</code>.</td>
</tr>

<tr valign="top">
    <td><a href="https://help.syncfusion.com/cr/maui/Syncfusion.Maui.Charts.DoughnutSeries.html" aria-label="View DoughnutSeries class in API reference">DoughnutSeries</a></td>
    <td>Plots <code>categorical data</code> as a <code>ring of slices</code> with a <code>hollow center</code>. Supports the same <code>explosion</code> and <code>grouping options</code> as PieSeries, exposes an <code>InnerRadius</code> to control the <code>hole size</code>, and accepts a <code>custom view</code> rendered in the <code>center</code>.</td>
</tr>

<tr valign="top">
    <td><a href="https://help.syncfusion.com/cr/maui/Syncfusion.Maui.Charts.RadialBarSeries.html" aria-label="View RadialBarSeries class in API reference">RadialBarSeries</a></td>
    <td>Plots data as <code>radial bars</code> that sweep from a <code>starting angle</code> to a <code>value-derived end angle</code>. Supports <code>gap ratio</code> between segments, <code>customizable cap shapes</code>, and <code>track fill and stroke</code> to display the <code>unfilled portion</code> behind each bar.</td>
</tr>
</table>
