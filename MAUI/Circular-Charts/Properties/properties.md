# API Reference for .NET MAUI Circular Chart

<br>

The Circular Chart API is documented across the pages below. Each page lists the public properties, methods, and events declared by a related group of classes.

<br>

<table>
<tr>
    <th>Page</th>
    <th>Contents</th>
</tr>

<tr valign="top">
    <td><a href="api-chart" aria-label="View Chart API reference">Chart</td>
    <td>
        Provides access to members of the <code>SfCircularChart</code> control. Use this reference when configuring the
        <code>circular chart container</code>, including the <code>series collection</code>,
        <code>title</code>, <code>legend integration</code>,
        <code>tooltip support</code>, <code>interactive behavior</code>,
        <code>plot area customization</code>, <code>chart image export</code>,
        <code>animation</code>, and overall <code>chart layout</code>.
    </td>
</tr>

<tr valign="top">
    <td><a href="api-legend" aria-label="View Legend API reference">Legend</a></td>
    <td>
        Lists members related to the <code>chart legend</code> and associated styling classes,
        including <code>ChartLegend</code> and
        <code>ChartLegendLabelStyle</code>.
        Use this reference for configuring
        <code>legend visibility</code>,
        <code>legend placement</code>,
        <code>floating legends</code>,
        <code>legend item templates</code>,
        <code>series visibility toggling</code>,
        and other <code>legend appearance settings</code>.
    </td>
</tr>

<tr valign="top">
    <td><a href="api-behavior" aria-label="View Behavior API reference">Behavior</a></td>
    <td>
        Lists members related to <code>tooltips</code> and
        <code>selection interactions</code> used by the circular chart,
        including <code>ChartTooltipBehavior</code>,
        <code>ChartSelectionBehavior</code>,
        <code>ChartSelectionChangingEventArgs</code>,
        and <code>ChartSelectionChangedEventArgs</code>.
        Use this reference for
        <code>customizing tooltips</code>,
        <code>programmatic tooltip operations</code>,
        <code>segment selection</code>,
        <code>selection highlighting</code>,
        <code>single and multiple selection modes</code>,
        and handling <code>selection-related events</code>.
    </td>
</tr>

<tr valign="top">
    <td><a href="api-series" aria-label="View Series API reference">Series</a></td>
    <td>
        Provides access to members of the circular chart series types, including
        <code>DoughnutSeries</code>, <code>PieSeries</code>,
        <code>RadialBarSeries</code>, and shared
        <code>CircularSeries</code> APIs.
        Use this reference when configuring
        <code>data binding</code>,
        <code>segment appearance</code>,
        <code>data labels</code>,
        <code>start and end angles</code>,
        <code>exploded segments</code>,
        <code>doughnut center content</code>,
        <code>radial bar tracks</code>,
        <code>grouping behavior</code>,
        and overall <code>series customization</code>.
    </td>
</tr>

</table>
