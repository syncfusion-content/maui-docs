# .NET MAUI CheckBox API Reference

The Syncfusion® .NET MAUI CheckBox (SfCheckBox) is a selection control that supports checked, unchecked, and intermediate states, with full support for styling, labeling, and state management.

This page provides a comprehensive reference for all available APIs of the SfCheckBox control.
