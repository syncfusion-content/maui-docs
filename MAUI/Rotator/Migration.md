# Migrating from Xamarin Rotator to .NET MAUI Rotator

To migrate easily from [Xamarin Rotator](https://help.syncfusion.com/cr/xamarin/Syncfusion.SfRotator.XForms.SfRotator.html) to [.NET MAUI Rotator](https://help.syncfusion.com/cr/maui/Syncfusion.Maui.Rotator.SfRotator.html?tabs=tabid-1), we kept all the APIs from Xamarin Rotator in .NET MAUI Rotator. However, to maintain the consistency of API naming in .NET MAUI Rotator, we renamed some of the APIs. The APIs that have been changed in .NET MAUI Rotator from Xamarin Rotator are detailed as follows.
