# .NET MAUI Chat API Reference

The Syncfusion® .NET MAUI Chat (SfChat) is a conversational control that supports rich messaging experiences, attachments, typing indicators, time breaks, avatars, and customizable message presentation.

This page provides a comprehensive reference for all available APIs of the SfChat control.
