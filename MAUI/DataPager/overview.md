# About Syncfusion .NET MAUI DataPager Control

The [.NET MAUI DataPager]() control is a standalone pagination control used to efficiently navigate through large datasets by dividing them into manageable pages. It provides a seamless user experience with intuitive navigation options and can be seamlessly integrated with data display controls like the SfDataGrid.

## Key features

- **Normal and On-Demand Paging** — Load entire data collection upfront or dynamically load pages on-demand for better memory efficiency.
- **Navigation options** — First, Last, Previous, Next, and numeric button navigation with programmatic page switching.
- **Customizable display modes** — Choose which navigation buttons to display (numeric only, navigation buttons, or a combination).
- **Button customization** — Configure button shape, size, and font size to match your application design.
- **Flexible orientation** — Display buttons horizontally or vertically based on layout requirements.
- **Auto-ellipsis support** — Automatically display ellipsis buttons for navigating large page ranges.
- **Style customization** — Comprehensive color and template customization for buttons and pager appearance.
- **Page change events** — Handle PageChanging and PageChanged events to perform custom operations.

## Business use cases

- E-commerce applications displaying large product catalogs with pagination controls.
- Data analytics dashboards requiring efficient navigation through large datasets.
- Admin panels and management systems handling user lists, orders, and transactions.
- Mobile applications with limited screen space needing efficient data presentation.
- Reports and data export scenarios where paginated views improve performance and usability.

## Namespace

To use the DataPager control in your .NET MAUI application, add the following namespace:

```
Syncfusion.Maui.DataPager
```
