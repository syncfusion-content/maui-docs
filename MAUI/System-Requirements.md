## System Requirements for .NET MAUI

The following table lists the minimum requirements for developing applications using Syncfusion® .NET MAUI controls.

<table>
    <thead>
        <tr>

            <td>

                    <li>.NET 9.0 or .NET 10.0</li>
                </ul>

            <td>
                <ul>
                    <li>Android SDK</li>
                    <li>Android API Level 21 or higher</li>
                    <li>Android Emulator or physical device</li>
                </ul>
            </td>
        </tr>

            <td><b>iOS</b></td>
            <td>iOS 12.2 or higher</td>
            <td>

                    <li>Visual Studio 2026 v18.0 or later</li>
                    <li>Visual Studio 2022 v17.12 or later</li>
                    <li>.NET 9.0 or .NET 10.0</li>
                </ul>
            </td>
            <td>
                <ul>
                    <li>Mac build host</li>

                    <li>.NET 9.0 or .NET 10.0</li>
                </ul>
            </td>
            <td>
                <ul>
                    <li>Xcode (version based on selected .NET MAUI release)</li>
                </ul>
            </td>
        </tr>

            <td>

                    <li>Visual Studio 2022 v17.12 or later</li>
                    <li>.NET 9.0 or .NET 10.0</li>
                </ul>
