# .NET MAUI Date Picker API Reference

The Syncfusion® .NET MAUI Date Picker (SfDatePicker) is a highly interactive UI control that lets users select a date within a specified range.

This page provides a comprehensive reference for the available APIs of the SfDatePicker control.
