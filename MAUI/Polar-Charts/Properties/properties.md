# API Reference for .NET MAUI Polar Chart

<br>

The Polar Chart API is documented across the pages below. Each page lists the public properties, methods, and events declared by a related group of classes.

<br>

<table>
<tr>
    <th>Page</th>
    <th>Contents</th>
</tr>

<tr valign="top">
    <td><a href="api-chart">Chart</a></td>
    <td>
        Provides access to members of the <code>SfPolarChart</code> control. Use this reference when configuring the
        <code>polar chart container</code>, including <code>series collection</code>,
        <code>primary and secondary axes</code>,
        <code>grid line rendering</code>,
        <code>palette customization</code>,
        <code>plot area appearance</code>,
        <code>chart title</code>,
        <code>legend integration</code>,
        <code>tooltip support</code>,
        <code>interactive behavior</code>,
        <code>chart rotation</code> through <code>StartAngle</code>,
        and overall <code>polar chart layout</code>.
    </td>
</tr>

<tr valign="top">
    <td><a href="api-legend">Legend</a></td>
    <td>
        Lists members related to the <code>chart legend</code>, <code>marker customization</code>,
        and supporting styling classes used by the polar chart, including
        <code>ChartLegend</code>,
        <code>ChartLegendLabelStyle</code>,
        <code>ChartMarkerSettings</code>,
        and <code>DoubleRange</code>.
        Use this reference for configuring
        <code>legend visibility</code>,
        <code>legend placement</code>,
        <code>floating legends</code>,
        <code>series visibility toggling</code>,
        <code>marker appearance</code>,
        and other <code>visual customization settings</code>.
    </td>
</tr>

<tr valign="top">
    <td><a href="api-behavior">Behavior</a></td>
    <td>
        Lists members related to <code>tooltips</code> and
        <code>selection interactions</code> used by the polar chart,
        including <code>ChartTooltipBehavior</code> and
        <code>ChartSelectionBehavior</code>.
        Use this reference for
        <code>tooltip appearance customization</code>,
        <code>programmatic tooltip operations</code>,
        <code>single and multiple selection</code>,
        <code>selection highlighting</code>,
        and handling <code>selection-related events</code>.
    </td>
</tr>

<tr valign="top">
    <td><a href="api-series">Series</a></td>
    <td>
        Provides access to members of the <code>PolarAreaSeries</code> and related
        <code>PolarSeries</code> APIs.
        Use this reference when configuring
        <code>polar area rendering</code>,
        <code>data labels</code>,
        <code>markers</code>,
        <code>series borders</code>,
        <code>dash patterns</code>,
        <code>data binding</code>,
        <code>closed polygon behavior</code>,
        and retrieving <code>data point information</code>.
    </td>
</tr>
