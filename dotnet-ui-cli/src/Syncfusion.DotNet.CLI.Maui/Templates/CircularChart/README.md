# Circular Chart template

This template displays category values with `SfCircularChart` and `PieSeries`
from `Syncfusion.Maui.Charts`.

See the [Syncfusion Circular Chart guide](https://help.syncfusion.com/maui/circular-charts/getting-started).

## Layout and sample data

The sample includes 12 product categories. The chart fills the page content area and uses its default palette and theme styling.

The heading uses a full-width page header, centered text, and a 24-point font.
