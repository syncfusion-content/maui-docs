# RichTextEditor Sample

A getting-started sample for the Syncfusion .NET MAUI `SfRichTextEditor` control.

## What it is

The `SfRichTextEditor` lets users edit HTML content with a built-in toolbar.

## NuGet package

`Syncfusion.Maui.RichTextEditor`

## Documentation

https://help.syncfusion.com/maui/rich-text-editor/getting-started

## Sample organization

- `RichTextEditorView.xaml` — the page hosting `SfRichTextEditor`, bound through its public `Value` property in the default HTML value mode.
- `RichTextEditorViewModel.cs` — holds the `HtmlText` string property.

## Layout and sample data

The editor fills the page content area and starts with project notes and a release checklist. Its HTML value uses two-way binding. Colors come from the default control and MAUI themes.
