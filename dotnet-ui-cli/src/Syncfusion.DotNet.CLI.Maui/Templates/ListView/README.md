# ListView Sample

A getting-started sample for the Syncfusion .NET MAUI `SfListView` control.

## What it is

The `SfListView` displays a list of items with a custom item template.

## NuGet package

`Syncfusion.Maui.ListView`

## Documentation

https://help.syncfusion.com/maui/listview/getting-started

## Sample organization

- `ListViewPage.xaml` — the page hosting `SfListView` bound to the view model.
- `ListViewViewModel.cs` — holds the `Books` collection of sample data.
- `ListViewModel.cs` — the data entity (implements `INotifyPropertyChanged`).

## Layout and sample data

The sample includes 75 distinct topic-and-guide entries. Rows size dynamically and text wraps as the window width or system font size changes. The list fills the page content area and inherits default MAUI text colors.
