# Scheduler Sample

A getting-started sample for the Syncfusion .NET MAUI `SfScheduler` control.

## What it is

The `SfScheduler` displays appointments on day, week, or month views.

## NuGet package

`Syncfusion.Maui.Scheduler`

## Documentation

https://help.syncfusion.com/maui/scheduler/getting-started

## Sample organization

- `SchedulerView.xaml` — the page hosting `SfScheduler` bound to the view model.
- `SchedulerViewModel.cs` — holds the `Appointments` collection of sample data.
- `SchedulerModel.cs` — the data entity (plain class).

## Layout and sample data

The sample includes 21 appointments over seven days, starting today. The scheduler fills the page content area and uses its default appointment colors.
