# Charts Sample

A getting-started sample for the Syncfusion .NET MAUI `SfCartesianChart` control.

## What it is

The `SfCartesianChart` displays data as a column series with category and numerical axes.

## NuGet package

`Syncfusion.Maui.Charts`

## Documentation

https://help.syncfusion.com/maui/cartesian-charts/getting-started

## Sample organization

- `CartesianChartView.xaml` — the page hosting `SfCartesianChart` bound to the view model.
- `CartesianChartViewModel.cs` — holds the `Data` collection of sample data.
- `CartesianChartModel.cs` — the data entity (plain class).

## Layout and sample data

The sample includes 12 months of revenue. The chart fills the page content area and uses its default palette and theme styling.

The heading uses a full-width page header, centered text, and a 24-point font.
