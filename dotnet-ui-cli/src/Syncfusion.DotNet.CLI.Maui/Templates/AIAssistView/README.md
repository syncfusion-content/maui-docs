# AssistView Sample

A getting-started sample for the Syncfusion .NET MAUI `SfAIAssistView` control.

## What it is

The `SfAIAssistView` displays a conversational assistant interface with messages.

## NuGet package

`Syncfusion.Maui.AIAssistView`

## Documentation

https://www.syncfusion.com/maui-controls/maui-ai-assistview

## Sample organization

- `AIAssistViewPage.xaml` — the page hosting `SfAIAssistView` bound to the view model.
- `AIAssistViewViewModel.cs` — holds a collection of the package's `AssistItem` model.

## Layout and sample data

The conversation fills the page content area and starts with a short example exchange. Responses are local demonstration text; connect an AI service in the request handler for real answers.
