# Diagram Sample

A getting-started sample for the Syncfusion .NET MAUI `SfDiagram` control.

## What it is

The `SfDiagram` displays basic flowcharts and interactive diagram.

## NuGet package

`Syncfusion.Maui.Diagram`

## Documentation

https://help.syncfusion.com/maui/diagram/getting-started

## Sample organization

- `DiagramView.xaml` — the page hosting `SfDiagram` control.
- `DiagramView.xaml.cs` — connects the page to its view model.
- `DiagramViewModel.cs` — creates the nodes and connectors for the sample workflow.

## Layout and sample data

The sample includes five connected workflow nodes. The diagram fills the page content area and fits the workflow when initialized or resized.
